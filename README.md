# 企业知识库

一个面向 Codex 桌面版、Obsidian 和飞书的单入口企业知识库插件。

管理员只需完成一次公司级配置，普通员工随后导入无密钥公司配置、使用本人飞书 OAuth，即可在 Codex 中查询、收录和发布同一套企业知识。

支持 Windows 和 macOS。安装后界面只显示一个 Skill：`企业知识库`。

最新安装包可在 [GitHub Releases](https://github.com/peter132277/enterprise-knowledge-base/releases/latest) 下载；也可以直接使用下面的 Codex 桌面版安装提示词。

## 一键安装

将下面一句话复制到 Codex 桌面版对话框发送即可。无需在终端执行 CLI 命令。

```text
请按照 https://github.com/peter132277/enterprise-knowledge-base/blob/main/INSTALL_REQUIREMENTS.md 的要求安装最新版“企业知识库”插件，安装后直接进入配置流程。
```

详细的安装、校验、安全和首次配置要求见 [INSTALL_REQUIREMENTS.md](INSTALL_REQUIREMENTS.md)。

## 基本功能

- 当前知识库问答：只查询当前 Vault 中经过审计的内容，并返回来源。
- 本地收录：支持文档、PDF、图片、网页、表格和普通附件。
- 音视频收录：默认使用飞书妙记；用户明确要求离线时才使用已经安装的 `whisper.cpp`。
- 企业发布：生成可读预览，确认后发布到精确映射的飞书 Wiki，并复用已经上传的 Drive 原件。
- 公司知识同步：员工首次配置、每个 Codex 会话首次企业查询、主动同步和发布成功后按确定性规则更新。
- Windows/macOS 安装向导：引导安装 Obsidian、配置相同的 Codex 项目与 Obsidian Vault，并完成飞书 OAuth。

## 公司默认权限

- 共享范围：全公司内部员工。
- 员工能力：查询、收录并发布企业知识。
- 普通员工飞书角色：空间成员，不是空间管理员。
- 外部分享：关闭。

应用安装、公司配置导入和 OAuth 不等于拥有知识空间权限。管理员必须单独预览并确认成员权限变更，写后回读通过才能导出员工配置。

## 管理员配置效果

管理员在 Codex 内完成：

1. 创建或连接企业自建应用。
2. 使用内置浏览器完成管理员本人 OAuth。
3. 选择唯一企业知识空间并建立精确目录映射。
4. 解析“全公司内部员工”，预览成员角色和全员功能策略。
5. 单独确认成员变更，写后重新读取成员列表验证。
6. 导出不含 App Secret、Token、Cookie 和员工名册的公司配置。

管理员本人也只能发布明确标记为企业属性且通过审核的内容。

## 普通员工配置效果

普通员工在 Codex 内完成：

1. 导入管理员提供的无密钥公司配置。
2. 使用本人飞书账号 OAuth。
3. 验证租户、精确空间、映射、本人成员权限和全员功能策略。
4. 验证通过后立即执行第一次只读企业知识同步。
5. 在当前对话直接开始查询、收录和发布企业知识。

每个新的 Codex 会话只在第一次企业查询前执行一次增量同步；同一会话后续查询复用本地镜像。系统不运行后台轮询。

## 个人知识安全边界

管理员和普通员工的个人知识一律纯本地：

- `scope: personal` 必须保持 `publish_to_feishu: false`。
- 个人附件、文档、图片、音视频和本地笔记不能进入发布队列。
- 个人原件不会上传到用于企业发布的 Drive。
- 个人知识不会进入飞书 Wiki、员工镜像或公司同步状态。
- 管理员身份不能绕过这条边界。

员工企业镜像只来自已验证飞书企业知识空间中的已发布内容，不复制管理员本地 Vault。镜像文件永久排除再次发布，防止循环创建。

## 轻量架构

- 一个插件、一个可见 Skill。
- 无数据库、无后台进程、无定时守护程序。
- 无专用 MCP、无自动模型下载、无第二套认证。
- 不新增第三方 Python 依赖。
- 查询和同步使用本地状态、节点身份、revision、指纹和内容哈希增量处理。

## 真实远端操作

以下操作始终需要各自的新明确授权：

- 修改飞书知识空间成员或权限。
- 创建知识空间。
- 上传到飞书妙记。
- 发布 Wiki 正文或 Drive 原件。
- 删除、移动、跨空间操作或开启外部分享。

一次授权不能自动扩展到另一种操作。
