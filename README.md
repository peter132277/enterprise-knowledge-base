# 企业知识库

一个由 Codex 直接读写本地 Markdown 和附件的单插件、单可见 Skill。Obsidian 仅作为人工浏览与编辑界面，不参与查询、初始化或自动化运行。

## 开始使用

1. 按 [图文安装 SOP](docs/manual-setup.md) 安装 Obsidian，并创建或打开一个 Vault。
2. 在 Codex 中以该 Vault 根目录创建名为“知识库”的项目。
3. 从 [Releases](https://github.com/peter132277/enterprise-knowledge-base/releases) 下载最新版 ZIP。
4. 在“知识库”项目中新建会话，把 ZIP 拖入输入框并发送：`帮我安装该 skill`。
5. 安装成功后，在“知识库”项目中再次新建会话，并发送：`初始化当前知识库`。

初始化只处理当前项目：零网络、零路径输入、零系统软件安装、零 `.obsidian` 写入。它会保留已有笔记和附件，并建立 Codex 项目根目录与 Vault 根目录的同根绑定。

## 能力与边界

- 查询：固定检索当前 Vault 的个人与企业知识，不提供个人／企业查询模式；候选召回使用 `rg`，缺失时回退到 Python 文件系统。
- 收录：支持文档、PDF、图片、网页、表格、音视频和普通附件；本地收录不访问飞书。
- 飞书：仅在启用后把 lark-cli 作为条件依赖；发布、妙记上传、成员和权限变更分别预览并分别确认。
- 安全：个人知识对管理员和员工都永久纯本地，不进入 Drive、Wiki、发布队列、企业镜像或同步状态。
- 运行：无数据库、后台进程、守护程序、定时任务、文件监控、专用 MCP、第二套认证或第三方 Python 依赖。

常用指令：直接提问、`收录这个文件`、`同步公司知识`、`发布到飞书`、`确认批量发布`、`检查知识库健康度`。
